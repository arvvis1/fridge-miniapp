# Mini App «Мой холодильник»

## Что уже сделано

- Адаптивный экран для телефона и компьютера.
- Добавление и удаление продуктов, количество.
- Разные рецепты из распознанных продуктов, которые уже есть в списке; недостающие продукты не предлагаются к покупке.
- Пошаговые рецепты, примерная калорийность и кнопка для просмотра следующих вариантов.
- В Telegram Mini App список хранится через Telegram Cloud Storage; вне Telegram для предпросмотра используется localStorage.
- Токен бота в браузерный код не добавляется.

## Как подключить в Telegram

1. Разместить `index.html` на публичном HTTPS-хостинге. Например, на бесплатном статическом хостинге. Пока страница лежит только на компьютере, Telegram на телефоне не сможет её открыть.
2. Скопировать публичный HTTPS-адрес страницы.
3. В Telegram открыть `@BotFather` → `/mybots` → выбрать бота → **Bot Settings** → **Configure Mini App** (или `/setmenubutton`) → указать этот адрес.
4. Открыть чат бота и запустить Mini App.

## Важно о данных

Список в Mini App хранится в Telegram Cloud Storage и принадлежит пользователю Mini App. Текущий чат-бот пока хранит отдельный список в локальном `fridge_data.json`; они автоматически не синхронизируются. Для общего списка между экраном Mini App и командами бота понадобится доступный через HTTPS сервер/API. Не помещайте токен бота в `index.html`.
